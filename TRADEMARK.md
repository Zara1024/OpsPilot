# OpsPilot Trademark and Brand Usage

The OpsPilot name, logo, domain names, visual identity, and related brand assets
are brand assets of the OpsPilot project. They are not licensed under the
AGPLv3 license.

The AGPLv3 license grants rights to use, copy, modify, and distribute the
source code under its terms. It does not grant permission to use OpsPilot brand
assets in a way that suggests official status, sponsorship, endorsement, or
affiliation with the OpsPilot project.

## Allowed uses

You may use the OpsPilot name when the use is truthful and not confusing, for
example:

- referring to the upstream OpsPilot open source project;
- stating that your project is based on, compatible with, or integrates with
  OpsPilot;
- linking to the official OpsPilot repository, website, documentation, or
  releases;
- using the OpsPilot name in issue reports, tutorials, blog posts, talks, or
  documentation about the project.

## Restricted uses

You may not use OpsPilot brand assets in a way that could confuse users about who
operates, maintains, sponsors, or endorses a product or service. For example,
you may not:

- present a fork, distribution, package, hosted service, SaaS offering, or
  commercial product as the official OpsPilot project;
- use names such as "OpsPilot Cloud", "Official OpsPilot", "OpsPilot Enterprise", or
  similar names for an unaffiliated service or product;
- use the OpsPilot logo or visual identity as the primary branding for an
  unaffiliated product, service, or company;
- register domains, social accounts, app names, package names, or organization
  names that imply official OpsPilot status or create user confusion;
- remove or alter OpsPilot branding in a way that misrepresents the origin of the
  upstream project.

## Forks and distributions

You may fork and redistribute the source code under AGPLv3, but forks and
redistributions must make their independent status clear. If you materially
modify the project, use a distinct product or service name and avoid implying
that your version is maintained, endorsed, or operated by the OpsPilot project.

## Commercial services

The source code license does not grant permission to use OpsPilot branding for a
commercial hosted service, SaaS offering, paid distribution, support package, or
enterprise product in a way that implies official status or endorsement.

If you want to use OpsPilot brand assets for a commercial service or partnership,
contact the maintainers for permission.
